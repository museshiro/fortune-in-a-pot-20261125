A make.fun entry for [Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9) — one kind, funny fortune for a houseplant, in 120 characters or fewer.

The fortune, as written by `main.ts` into `entry.txt`:

> You will outgrow this pot by spring, and your keeper will pretend she planned it all along.

Run it with Node 22: `node main.ts`. It writes the fortune to `entry.txt` (and to `/output/entry.txt` when that directory exists, as the grader expects).
